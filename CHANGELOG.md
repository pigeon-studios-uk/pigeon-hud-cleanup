# Changelog

All notable changes to Pigeon HUD Cleanup are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- **Major** versions can need changes to your configuration or other resources. Read the **Upgrade notes**.
- **Minor** versions add features without breaking existing setups.
- **Patch** versions fix bugs only.

## [Unreleased]

First release.

### Highlights

- Fourteen parts of GTA's HUD, each hidden or kept
- Crosshair hidden, kept for snipers if you like
- Minimap always, in vehicles only, or never

### Added

- `Config.Hide`, with wanted stars, cash, Online cash, cash changes, vehicle name and class, area and street names, the radio station name, the weapon icon, weapon wheel stats, the crosshair, the saving spinner and Online messages.
- `Config.KeepSniperReticle`, to keep the crosshair for sniper rifles.
- `Config.Minimap`: `'always'`, `'vehicle'` or `'never'`.
- The minimap shown again when the resource stops.
- Update checker from the Pigeon Studios version registry.
